# budget-revenues-analysis
# Анализ и прогнозирование доходов бюджета Москвы

## Описание
Проект выполнен в рамках курса «Прикладной анализ данных в экономике, финансах и управлении».

## Файлы
- `dataset1_cleaned_budget_revenues.csv` – очищенные исторические данные (702 строки, 7 колонок)
- `dataset2_revenue_forecast.csv` – прогноз на 4 квартала
- `Рабочая_тетраль_итогового_проекта_Каменская_группа_2.ipynb` – Jupyter Notebook с полным кодом
- `Презентация для итогового проекта Каменская группа 2.pptx` – презентация для защиты

## Результаты
- Корреляция план–факт: 0.86
- MAPE прогноза: 4.01%

## Как использовать
Откройте рабочую тетрадь в Google Colab или Jupyter, выполните ячейки.
